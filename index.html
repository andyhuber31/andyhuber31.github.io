Ubuntu NTP Server

Verifying an HSRP Gateway from Ubuntu

I used route and neighbor-table output to identify Ubuntu’s next hop for another VLAN and verify the MAC address associated with the HSRP virtual gateway.

  • HSRP
  • Routing
  • ARP
  • Troubleshooting

Verified result: Ubuntu selected 10.31.62.1 for traffic to 10.31.93.100. Its neighbor table mapped that gateway to 00:00:0c:07:ac:3e, the HSRP version 1 virtual MAC for group 62, with the neighbor marked REACHABLE.

Verification snapshot: October 12, 2026 (Arizona time). This example checks the host’s route selection and gateway neighbor entry.

View gateway verification output 
$ ip route get 10.31.93.100
10.31.93.100 via 10.31.62.1 dev enp1s0 src 10.31.62.62 uid 1000
    cache

$ ip neigh show 10.31.62.1
10.31.62.1 dev enp1s0 lladdr 00:00:0c:07:ac:3e REACHABLE
